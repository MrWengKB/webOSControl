# v0.1.10
- Search YouTube from the phone. YouTube on LG TVs ignores typed text, so when YouTube is on screen the keyboard becomes "Search YouTube" and opens YouTube's results for what you type

# v0.1.9
- Colour buttons back to plain buttons without labels or ? (the TV already shows their functions when you press Up)

# v0.1.8
- Colour buttons show their Live TV functions (red: Subtitles, yellow: Dual sound)
- A ? beside each colour button explains that what they do changes from app to app

# v0.1.7
- Removed press-and-hold on OK and the touchpad (the TV didn't respond to it)
- Long-pressing an app in the Apps list shows how to uninstall it with the LG remote

# v0.1.6
- Press and hold OK or the touchpad to hold the remote's button, like the LG remote (e.g. app list edit mode)
- Uninstall: LG TVs refuse uninstall requests from phone apps, so long-pressing an app in the Apps list now opens the TV's app list with steps to remove it via hold and X

# v0.1.5
- Uninstall: show the TV's answer in a popup instead of a message hidden behind the Apps list

# v0.1.4
- Uninstall TV apps: long-press an app in the Apps list and confirm (experimental, some TVs may refuse)

# v0.1.3
- Check for updates: on launch the app looks for a newer release and asks whether to Update or Ignore
- "Check for updates" button at the bottom of the TV list
- Test (debug) builds install as a separate app, so they no longer block release updates

- Fix typing on the TV (e.g. YouTube search): the app now registers as the TV's remote keyboard
- Letters and backspaces are sent live as you type; Enter on the phone keyboard submits
- The keyboard opens by itself when a text box is selected on the TV
